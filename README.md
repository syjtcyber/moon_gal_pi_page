문갈피

마음에 남은 문장과 장면을, 내 말과 함께 다시 꺼내볼 수 있도록 기록하는 작은 웹 앱입니다.

정확한 문장을 남기고 싶을 때는 문장갈피에,
대사는 기억나지 않아도 오래 남은 순간은 장면갈피에 적어둘 수 있어요.

사용 방법
문갈피_v0.6.2.html 파일을 실행합니다.
문장 또는 장면 탭을 고릅니다.
기억하고 싶은 내용을 적고 등록 또는 장면 남기기를 누릅니다.
저장된 카드에서 수정·삭제하거나, 문갈피 만들기로 PNG 이미지를 저장할 수 있습니다.
사진 속 문장 가져오기
문장 탭에서 사진 속 문장 가져오기를 엽니다.
캡처 이미지나 사진을 선택합니다.
글자 읽기를 누릅니다.
인식된 초안을 직접 확인하고 고칩니다.
문장칸으로 가져오기를 눌러 등록합니다.

선택한 사진은 저장되지 않습니다. 처음 글자를 읽을 때는 인터넷 연결이 필요할 수 있어요.

PNG 문갈피 만들기

저장된 문장 또는 장면 카드에서 문갈피 만들기를 누르면 이미지로 저장할 수 있어요.

세로형 · 가로형 선택
문장 정렬과 위치 선택
글자 크기 작게 / 보통 / 크게 선택
출처·작품명과 내 반응 정렬
내 코멘트·감상을 이미지에 넣거나 빼기
이미지에만 적용되는 줄바꿈 편집
PNG 아래에 생성 날짜와 시간이 표시됩니다.

이미지 설정은 기록 원문을 바꾸지 않습니다.

데이터 저장과 백업

작성한 기록은 이 브라우저의 LocalStorage에 저장됩니다.

회원가입이나 서버가 필요하지 않습니다.
같은 브라우저에서 파일을 다시 열면 기록이 유지됩니다.
다른 기기나 브라우저와 자동 동기화되지는 않습니다.
브라우저 데이터 삭제, 기기 변경, 파일 실행 위치 변화에 대비해 가끔 백업 저장을 해주세요.
백업 파일은 백업 불러오기로 다시 가져올 수 있습니다.

제작 의도

문갈피는 좋은 문장을 모으는 데서 끝나지 않고,
그 문장이나 장면이 내게 왜 남았는지 함께 기억하기 위해 만들었습니다.

남에게 보여줄 완성된 감상문이 아니라,
나중의 내가 다시 책을 펼쳤을 때
“나는 여기서 이런 마음이었구나” 하고 알아볼 수 있는 작은 책갈피가 되었으면 합니다.
