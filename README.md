# 문갈피

마음에 남은 문장과 출처, 개인적인 코멘트를 함께 기록하는 작은 웹 앱입니다.

## 버전

**v0.4.1**

## 주요 기능

- 문장, 출처, 코멘트 등록
- 등록한 문갈피 수정 및 삭제
- 문장·출처·코멘트 검색
- 문갈피를 눌러 코멘트 펼치기·접기
- 문갈피별 PNG 이미지 저장
- 종이, 세이지, 벚꽃, 브라운, 다크 테마
- 브라우저 자동 저장

## 사용 방법

1. `문갈피_v0.4.1.html` 파일을 실행합니다.
2. 문장과 출처, 코멘트를 입력합니다.
3. **등록** 버튼을 누릅니다.
4. 등록한 문갈피에서 수정, PNG 저장, 삭제 기능을 사용할 수 있습니다.

## 데이터 저장

작성한 내용은 브라우저의 `LocalStorage`에 저장됩니다.

- 별도의 회원가입이나 서버가 필요하지 않습니다.
- 같은 브라우저에서는 파일을 다시 열어도 기록이 유지됩니다.
- 다른 기기나 다른 브라우저와 자동으로 동기화되지는 않습니다.
- 브라우저 데이터를 삭제하면 기록도 함께 사라질 수 있습니다.

## PNG 저장

각 문갈피의 **PNG** 버튼을 누르면 해당 문갈피를 이미지로 저장합니다.

상단의 **PNG 저장** 버튼은 현재 화면에 보이는 첫 번째 문갈피를 저장합니다.

PNG 저장 기능과 웹폰트 사용에는 인터넷 연결이 필요할 수 있습니다.

## 실행 환경

별도의 설치 없이 최신 웹 브라우저에서 실행할 수 있습니다.

- Chrome
- Edge
- Samsung Internet
- 기타 최신 브라우저

## 제작 의도

좋은 문장을 수집하는 데서 끝나지 않고,  
그 문장을 읽었을 때의 생각과 감정까지 함께 남기기 위해 만들었습니다.
